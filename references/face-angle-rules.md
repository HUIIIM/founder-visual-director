# 脸角度自然感三规则

> 来源提炼：CEO 亲研笔记《脸角度自然感》（2026-10-03）；起因是晨跑抓拍 v2 因"头身方向脱节"被打回。
> 配套制度：CEO 终审亲眼制——所有人物视觉，终审时亲自全尺寸过一遍头身夹角 + 视线落点，不信专员自报。

## 规则 1：头–身夹角

| 头与躯干朝向夹角 | 观感 | 条件 |
|---|---|---|
| ≤30° | 自然 | 无条件 |
| 30–45° | 需解释 | 必须有视线落点（在看某个具体东西） |
| >45° | 假 | 除非同时满足：强注视物 + 肩膀跟转 + 表情配合 |

## 规则 2：视线必须有落点

眼睛不能"看空气"。每个转头都必须回答：**他在看什么？**

常见合法落点：
- 跑步：前方路面 / 迎面来的人 / 远处天际线
- 行走：橱窗 / 同行的人 / 手里的手机
- 静止：镜头（摆拍成立）/ 手里的东西 / 对话者

没有落点的转头 = 摄影师指挥的痕迹 = AI 感，打回。

## 规则 3：动量一致性

身体有动量（跑 / 走 / 转身）时，头要么顺动量（看行进方向 ±20°），要么有明确理由逆动量。

## 摆拍与抓拍没有中间态

- **摆拍成立**：眼神给镜头，身体舒展，允许 45° 以上的头身夹角（时尚大片常见）。
- **抓拍成立**：身体在动量中，眼神在环境里有落点，头身夹角 ≤30°。
- 身体是抓拍、头是摆拍，两套逻辑拼在一起 = "摆出来的抓拍"，必打回。

## 事故案例（内化教训）

晨跑抓拍 v2 的死因：身体正对镜头跑步（前冲动量），头向左拧约 70–80° 接近侧面，眼睛盯着左前方空气——
现实中这种组合几乎不存在（真实对应物只有"被侧面巨响吸引的惊转"，但那会伴随肩膀跟动 + 表情变化）。
人脑对这种"头身方向脱节"极敏感，一眼假。

返工方向（二选一）：
- A：顺动量——脸朝跑步方向，微转 ≤20°，眼睛看前方路面或迎面；
- B：小角度 + 落点——四分之三侧面（≤30°），眼睛落在画面内可见的某个人/物上。
不许再出现 >45° 无落点拧头。
