# 背景专项：背景必须"长"在生活里

> 来源提炼：董事长 2026-10-02 亲口补"还有背景"；虚化物理对标大师标准 M7。
> 背景是最快的穿帮信号，也是最容易被忽略的检查项。

## 1. 存在理由

背景必须有 2–3 个生活化细节（书脊、半杯水、微乱的桌面、长椅上的水瓶、路上的落叶），
拒绝"样板间式"过分整洁——**过分整洁是最快的穿帮信号**。

## 2. 虚化必须符合物理

- 虚化程度 / 光斑形状对得上宣称的光圈焦段（如 85mm f/1.8 的景深表现）；
- 同一平面不许一半清晰一半糊；
- 背景做三层检查：近 / 中 / 远应有虚化梯度，有过渡层，不许一刀切全虚。

## 3. 背景光影与主体是同一个光源

背景的明暗方向、色温必须和脸上的光对得上。
背景里出现第二光源、却在脸上找不到对应 = fail。

## 4. 背景物体功能与逻辑

- 文字招牌每个字可读且拼写正确；
- 重复物体（椅子、窗户、书）纹路稳定不串；
- 人群四肢完整，不缺胳膊少腿。

## 5. 拒绝"假大空"豪华背景

无来由的水晶灯、大理石、落地窗夜景硬堆 = low 感。
奢华必须长在生活里：old money 是"住"出来的，不是"摆"出来的。
每个奢品镜头都要回答"他凭什么"——船 / 车 / 表永远是背景，人是主角，配文谈建造、谈工作节奏、谈思考。
