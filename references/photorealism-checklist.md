# 真实感检查清单："真实感 = 可控的瑕疵"

> 来源提炼：深度研究报告《AI 照片真实感审查标准》（22 源）+ 董事长"不要像 AI 造出来的照片"硬线。
> 方法：100%–200% 放大逐项查。任一红线项 fail → 打回全场景重生成，不许局部修补蒙混。
> 终判四字："像真拍的"。存疑即打回。

## A. 解剖学（放大逐项查）

1. **皮肤**：可见毛孔 / 细纹 / 瑕疵，质感与年龄相称。蜡质、塑料感、过度磨皮 = fail。
2. **眼睛**：双眼角膜反光（catchlight）形状、位置一致，对应场景中同一真实光源；瞳孔正圆、虹膜有细节。
3. **牙齿**：颗颗分明；一整块白板、牙齿叠压嘴唇 = fail。不露齿时记 n/a。
4. **手**：指数、关节弯曲合理，饰品不融化进皮肤。策略：尽量避免手部特写（模型最弱环）。
5. **耳 / 眼镜 / 配饰**：耳廓左右自然不对称；眼镜框不变形、镜腿连接合理、双侧镜片反光一致（眼镜是最难的配件，重点查）。
6. **头发**：发丝不糊进背景，发际线自然；不许出现"风吹得和场景无关"的发型。

## B. 物理学（最耐用的信号）

7. **光影一致性**：所有阴影指向同一光源；阴影形状对得上投射物；物体与接触面之间有环境遮蔽；脸上的光与背景光源是同一个。
8. **反射一致性**：窗户 / 镜面 / 眼镜 / 金属里的反射世界必须与场景一致（人数、衣着、姿态对得上）。无镜面时记 n/a。
9. **透视与功能**：直线不弯；背景小物件功能合理（拉链能拉、杯子能拿、椅子能坐）。

## C. 全局观感（防"过完美"）

10. **不许过度对称、过度英俊、过度电影感**：真脸不对称；统计学平均脸 + 诡异的"记不住" = AI 味。
11. **可控瑕疵**：真机必有噪点底——暗部颗粒、轻微暗角、不完美白平衡、高光溢出、暗部死黑。
    "处处清晰、处处干净" = fail。

## D. 一票否决纪律

- 任一 A / B 项 fail → 打回全场景重生成。
- C 项两条为强疑问项：任一条明显违反，同样打回。
- 审查官对任何一项"存疑"，按 fail 处理。
