# references 五段式重写 exemplar（D-011，1/6）
五段式：背景/适用边界/操作步骤/反例/自检清单。

## 以 photorealism-checklist 为例
### 一、背景
AI 生图"像照片"不等于真实照片；本清单用于发布前拦截一眼假。
### 二、适用边界
适用于创始人人像/场景实拍风；不适用于信息图/插画风（走对应规范）。
### 三、操作步骤
1. 全尺寸点开；2. 查手/耳/文字三崩点；3. 查光影方向一致性；4. 查背景透视。
### 四、反例（Do-not-use-for）
不许用本清单给纯 AI 插画"验真"；不许跳过全尺寸目检只看缩略图。
### 五、自检清单
- [ ] 全尺寸目检完成 - [ ] 三崩点通过 - [ ] 光影一致 - [ ] 结论：通过/打回（注明条目）
