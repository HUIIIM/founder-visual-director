# 轮换铁律与台账制度

> 来源提炼：本项目创始人视觉规范（资产策划与轮换制度相关条款）。
> 目的：杜绝"白底标准照三连"类事故——根因是无调度纪律 + 头像用途未锁定 + 无人检查重复。

## 场景大类（判定粒度）

按大类判重复，**大类相同即判重复**（保守口径，不抠字眼）：

白底棚拍 / 室内书房 / 室内生活摆拍 / 城市街景 / 户外运动（跑步/骑行/球类）/
咖啡馆餐饮 / 旅行度假（海滩/游艇/山野）/ 商务场合 / 宠物 / 交通工具（车/机）/
校园 / 晚宴社交 / 其他（新出现的大类先归"其他"并登记）

## 轮换四条

1. **相邻 3 篇不重复**：同服装 / 同场景大类 / 同造型，三者任一重复即违规。
2. **carousel 内多图**：必须不同场景大类，或显著不同构图（全身 vs 特写可接受，同姿势同景别不可）。
3. **同一场景大类 14 天内不重复**（按制作/发布日期孰早）。
4. **S 级资产省着用**：S 级每月 ≤2 次，封面优先；白底棚拍原片作内容配图每月 ≤1 次，且不得连续两篇使用白底。

## 白底三禁（事故级）

1. 白底标准照（白底站姿抱臂标准头像）**永不作内容配图**——账号头像 + 正式场合专用。
2. 白底棚拍原片作内容配图每月 ≤1 次。
3. 作内容配图 = 事故，回滚 + 复盘。

## 冷却期

- S 级：30 天
- A 级：21 天
- B 级：14 天

同一 ID 在冷却期内不得重复使用。每次使用后 24h 内登记台账"使用记录"。

## 台账与调度单

- 台账：`used-visual-ledger.md`（由调用方在本地维护，不在本仓库内）。凡"已发布"的图永久退役，绝不二次使用（含裁剪、调色、局部复用、换平台复用）。
- 出图前先查台账查重；发布后 24h 内回写；漏记按流程缺陷处理。
- **视觉调度单制度**：任何图文/视频交付必须附调度单——资产 ID、上次使用时间（查台账）、本次选用理由、冷却期检查（通过/冲突）。无调度单的交付一律打回。
- 台账滞后时的降级规则：以实物（已生成的版本文件）为准做检查，并在结论中明确标注"台账待补、按实物判定"，同时记一条台账补录待办。

> 正式格式已落地：`references/ledger-format.md`（v1.0）——字段名与本草案完全一致（不得另起一套），
> v1.0 定机器可读载体（markdown 中 ```json 条目块）、补结构化参考图字段 `references` 与预留字段。
> 机器实现已落地：`scripts/check_rotation.py`（相邻 3 篇 / 14 天 / 冷却期真读台账判定）、
> `scripts/check_face_consistency.py`（anchor/参考图哈希核验）、`scripts/ledger_lib.py`（解析与字段校验）。
