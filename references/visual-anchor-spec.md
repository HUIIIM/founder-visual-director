# 固定视觉锚点规范（不出镜内容统一视觉符号）v1.0
来源：MV189（2026-10-05 立项）| 对齐：深沉 v5 视觉标准

## 锚点三件套（所有不出镜内容必须三者齐全）
1. **版式锚点**：信息分层固定——标题区上 1/3 处、左对齐；主体信息中下 2/3；页脚窄条只放 vertciti 字标 + 日期。禁止居中标题（v5 规定）。
2. **字体锚点**：标题用中文黑体粗排（Noto Sans SC Bold / 思源黑体 Heavy 级别），英文/数字用无衬线全大写 small-caps；正文字号 ≤ 标题的 1/3。字号层级不超过 3 档。
3. **配色锚点**：深沉底（近黑色，具体色值以 vertciti-brand-bundle.json VIZ3 为准）+ 单一强调色（每批内容一个强调色，批内不换）；强调色只出现在 ≤10% 面积（标题关键词/数据/分隔线）。

## 目检三条（新出 3 条内容验收）
- 三条并排：版式骨架一致、字体层级一致、强调色同一；
- 与深沉 v5 对齐：摄影基底 + 暗调电影质感 + 信息嵌入画面；禁平面色块标题卡。

## 变更规则
锚点变更须走 v5 视觉标准修订流程；单条内容不得私自换锚。
