## 图上的约定

- 所有戒面稿画的是**蜡印**（正读；兽朝 dexter，即观者左）。金面是它的左右镜像，由工具生成，不单独画。
- 画幅就是 12x10 戒面的**净刻面**：椭圆 8.2 x 10.2mm，长轴竖置（沿手指方向）。SVG 的宽高以 mm 标注，按 100% 打印即实寸。
- **黑＝下刀处**（金面上的凹，蜡印上的凸）。主纹里的**白线＝留金不刻**（蜡印上是凸起里的沟）。
- 虚线椭圆是净刻面边界，只是构造线，不入刻；面上无框线。
- 贯穿全部稿件的是同一棵苗：一茎两叶。在虎稿里它是虎自己的一道纹，在「破土」稿里它是主纹，在花押里它是骨架。

## 自检结论（按实寸读图）

每稿都按 12x10 实寸（约 300dpi 等效）与 32px 两档各看了线稿与剪影。如实记录：

| 稿 | 线稿，实寸 | 线稿，32px | 剪影（内部线全灭） |
|---|---|---|---|
| A1 | 读作「张口的带纹猛兽首」，叫得出虎 | 仍读作带纹兽首 | 读作「张口猛兽首」，**分不出虎与熊、狮**——虎的判定靠条纹 |
| A2 | 一口叫得出虎脸 | 仍是虎脸 | 读作「猫科正脸」，**分不出虎与猫** |
| A3 | 读作「带钩喙的怪兽首」，**叫不出虎** | 读作带刺的兽首 | 同左 |
| B1 | 一口叫得出苗 | 仍是苗 | 仍是苗 |
| B2 | 一口叫得出苗 | 仍是苗 | 仍是苗 |

规格的剪影逻辑要求「内部线全灭、轮廓仍读得出」。按这条严格执行：**两张苗稿通过；三张虎稿的剪影都只读到「兽首」，读不到「虎」**。这不是画得不够的问题，是规格自己指出的事实（「无额纹则读作豹脸」）：虎与其他大猫的区别就在条纹上。这一点如何裁量，交大师轮（见下）。

撤掉的一稿：「破土」原有第三稿（弓钩出土——幼苗弯着脖子顶出土面）。实寸读图读成垂头的花或牧杖，叫不出苗，已撤，不交。
