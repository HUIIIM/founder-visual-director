# 数据处理说明 / Data handling

## 本仓库存什么
- 只有文字：skill 定义、规范文档、校验脚本、demo 代码与样例输出、文本夹具。**不含**任何照片、视频、声音样本、克隆素材或真实台账。
- demo 与 `scripts/` 只读本地文件、写本地输出目录（`demo/output/` 或 `FVD_DEMO_OUT`），不联网、不上传。

## 仓库外的数据（skill 引用、但不在这里）
SKILL.md 涉及真人（创始人）的肖像资产，这些资产只存在于调用者自己的环境：

| 数据 | 位置 | 说明 |
|---|---|---|
| 白底标准头像 | 调用者本地工作区 | 只作身份锚参考图与账号头像，永不作内容配图 |
| 素材台账 `used-visual-ledger.md` | 调用者本地（`FVD_LEDGER_PATH`），仓根同名文件已列入 `.gitignore`，请勿提交 | 格式见 `references/ledger-format.md`；记录已发布素材、服装、场景大类、参考图哈希 |
| 数字人克隆素材（`model_id`） | 外部生产管线 | 需本人授权建档；授权过期或用途变更即停用。**停用机制由外部管线实现，本仓库没有相关代码** |

- 留存与删除：由调用者的工作区与生图服务的策略决定；本仓库不做也无法保证。
- 第三方：所用模型 / 生图服务如何处理上传的参考图，取决于调用者的服务商与配置，本仓库未核实。

## AI 生成内容标识
交付物与台账条目带 `ai_generated` / `ai_disclosure_*` 字段（SKILL.md 交付格式第七节），发布时须按平台规则显式标注；
具体法规适用由发布者判断。
